# Night 1

Night 1 of building my own tech ecosystem with Hack Club. Hey everyone, this is Fro-OS, an entire operating system I built over the last four months that runs inside a browser. Right off the bat we have widgets like a Pomodoro timer, task manager, weather application, motivational quotes and interactive pets.

It contains its own browser, a fully functional terminal, note taking application, file explorer, event management system, calculator, music player, toolbox and some AI magics. It even has an app launcher to run its own native applications. I'll be breaking this down over the next 24 days. Hit follow for Night 2 and join Hack club.
